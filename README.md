# atmos_rank

🛸 **Единый реестр спортсменов, спортивных разрядов и учеников Академии пилотов «АтмоС»**

Интерактивный дашборд на **Streamlit** для мониторинга присвоения официальных спортивных разрядов по гонкам дронов (беспилотных воздушных судов), просмотра приказов спорткомитетов и ведения базы учеников.

---

## ⚡️ Возможности
- 📋 **Сводный реестр**: гибкая фильтрация, поиск по ФИО, отбор по городам и категориям разрядов.
- 🎛️ **Управление столбцами**: скрытие и добавление столбцов таблицы в один клик, быстрые пресеты.
- 🎓 **База учеников Академии «АтмоС»**: учёт обучающихся, привязка договоров и актуальный статус аттестации.
- 📑 **Приказы и фотокопии**: детальная информация по каждому приказу с просмотром оригинальных сканов документов.
- 📊 **Аналитика**: интерактивные графики распределения разрядов, возрастного состава и филиалов.
- 👤 **Персональное досье**: индивидуальная карточка пилота с таймлайном спортивных достижений.
- 🌓 **Тёмная тема (Dark Mode)**: стильный стеклянный UI для комфортной работы.

---

## 🚀 Запуск проекта

### Вариант 1. Через Docker (рекомендуется)
```bash
docker compose up -d --build
```
Приложение откроется по адресу: [http://localhost:8501](http://localhost:8501)

### Вариант 2. Локально с Python (.venv)
```bash
./run.sh
# или
./start.command
```
Либо вручную:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
